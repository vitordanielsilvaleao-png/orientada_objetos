# Sistema de Gestão Financeira Pessoal

Projeto Integrador da disciplina de **Programação Orientada a Objetos**, desenvolvido em grupo como aplicação prática dos conceitos de POO.

## 📋 Sobre o projeto

O projeto consiste no desenvolvimento de um **Sistema de Gestão Financeira Pessoal**, permitindo trabalhar progressivamente os principais conceitos de Programação Orientada a Objetos.

O desenvolvimento seguirá as 16 missões propostas no projeto, evoluindo desde os fundamentos de POO até a integração final do sistema.

## 🎯 Objetivos

* Aplicar os fundamentos de Programação Orientada a Objetos na prática;
* Desenvolver código organizado, legível e preparado para manutenção;
* Aplicar conceitos como classes, encapsulamento, herança, polimorfismo, exceções, interfaces e persistência;
* Registrar as decisões técnicas e a evolução do projeto;
* Trabalhar colaborativamente utilizando Git e GitHub.
