**Essencial** é o requisito sem o qual o sistema não entra em funcionamento. Requisitos
essenciais são requisitos imprescindíveis, que têm que ser implementados
impreterivelmente.


### [RNF001] Desempenho

A aplicação deverá apresentar tempo de resposta de até 2 segundos para operações comuns, como consultas e registros de empréstimos.

**Prioridade**: Essencial

### [RNF002] Disponibilidade

A aplicação deverá estar disponível durante o horário de funcionamento da biblioteca, exceto em períodos previamente programados para manutenção.

**Prioridade**: Essencial

### [RNF003] Usabilidade

A interface deverá apresentar mensagens claras ao usuário quando uma operação for concluída com sucesso ou quando ocorrer algum erro.

**Prioridade**: Essencial

### [RNF004] Compatibilidade

A aplicação web deverá ser compatível com as versões atuais dos navegadores Google Chrome, Mozilla Firefox, Microsoft Edge e Safari.

**Prioridade**: Essencial

### [RNF005] Backup

O sistema deverá realizar backup automático dos dados da aplicação pelo menos uma vez ao dia.

**Prioridade**: Essencial

### [RNF006] Recuperação de dados

O sistema deverá permitir a restauração dos dados a partir do backup mais recente em caso de falha ou perda de informações.

**Prioridade**: Essencial

### [RNF007] Integridade dos dados

O sistema deverá garantir a consistência dos dados durante operações de cadastro, alteração, empréstimo e devolução de livros.

**Prioridade**: Essencial

### [RNF008] Manutenibilidade

A aplicação deverá ser desenvolvida utilizando uma arquitetura modular, permitindo a alteração de um módulo com impacto mínimo nos demais componentes.

**Prioridade**: Essencial
